### 🔥 Featured Spotlight Project

<div align="center">
  <h3>⚡ <a href="https://github.com/Yasho4867/triune-transformer">Triune Transformer</a></h3>
  <p><i>An experimental language-model architecture designed for dynamic compute exit routing, gated linear attention, and memory-efficient training.</i></p>
</div>

* ⚡ **Gated Linear Attention (GLA)**: High-efficiency linear attention with ELU+1 feature maps and RoPE.
* 🧠 **3-Tier Adaptive Exits (Reflex / Limbic / Cortex)**: Dynamic token routing exiting early at layer 6 (Reflex), layer 16 (Limbic), or full depth 24 (Cortex).
* 🔀 **Mixture-of-Experts (MoE)**: Top-$K$ routing with shared expert baselines and centroid-based routing state updates.
* 🎛️ **Centroid-Steered GaLore Optimizer**: Low-rank subspace gradient projection with parameter steering.
* 🚀 **Hardware Accelerated**: Native PyTorch AMP, Transformer Engine, and Blackwell NVFP4 block scaling support.
